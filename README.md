# Как туда попасть? — Африка

Первая публичная версия независимого русскоязычного справочника по въезду в Африку.

В этой версии опубликована главная страница с каталогом направлений. Карточки стран и территорий пока не открывают отдельные страницы: материалы по направлениям будут добавляться постепенно после проверки данных.

## Локальный запуск

```bash
npm install
npm run check
npm run dev
```

## Сборка

```bash
npm run build
```

Проект: Astro + TypeScript, статическая генерация, GitHub Pages.
