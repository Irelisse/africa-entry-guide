# Как туда попасть? — Африка

Первая публичная версия независимого русскоязычного справочника по въезду в Африку.

Проект перенесён из репозитория [Irelisse/africa-entry-guide](https://github.com/Irelisse/africa-entry-guide) для дальнейшей разработки в среде AI Studio Build.

## Состав проекта
- **119 направлений**: суверенные государства, частично признанные образования, спорные территории, зависимые территории, заморские департаменты, европейские территории в Африке, автономные регионы и особые географические случаи.
- **Все 61+ локальных флагов** стран и удалённые векторные флаги для специальных юрисдикций.
- **Оригинальная типографика и дизайн**: шрифты *Cormorant Garamond* и *Manrope*, глубокая оливковая гамма (`#17382f`), фоновое изображение Deadvlei (Намибия), сетка каталога и адаптивная верстка.
- **Интерактивные возможности**:
  - Мгновенный поиск по названию, коду страны (ISO-2) или юрисдикции.
  - Фильтрация по типам территорий.
  - Карточки с подробными метаданными и статусом подготовки материалов.
  - Навигация по разделам «О проекте», «Направления» и странице «Лицензии».

## Сборка и тестирование
- `npm run build` — сборка проекта
- `npm run lint` — проверка типов TypeScript
- `node --test src/utils/registry.test.ts` — запуск модульных тестов
